# Frameless-Game-Zing

**MONEY CITY — 20-month final incubation presentation (12 slides).**

`index.html` is the whole presentation in a single self-contained file: images, fonts (Kanit, Noto Sans Thai, Lilita One, all under the SIL Open Font License), icons, the QR code and every script are embedded. No internet connection is needed.

Double-click `index.html` to open it in Chrome or Edge.

| Key | Action |
| --- | --- |
| → / Space / PageDown / mouse wheel down | Next slide |
| ← / PageUp / mouse wheel up | Previous slide |
| Home / End | First / last slide |
| F | Fullscreen |
| N | Speaker notes (editable, with a timer) |
| O | Slide overview map |
| R | Replay the slide's animation |
| H | Hide or show the HUD |
| M | Sound (off by default) |
| L | Reduced-motion mode |
| Esc | Close overlays |

On slide 1 you can double-click the portrait frame to add a real photo of the entrepreneur. The photo is saved in your browser only; Shift+double-click removes it.
